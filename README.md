# HuaRec 花录 · 电影感网页录屏

一键起录、本地秒存、自带电影感运镜与 macOS 风背景的 Chrome 网页录屏插件。

## 项目基础信息

| 项 | 内容 |
|---|---|
| 名称 | HuaRec 花录 · 电影感网页录屏 |
| 版本 | 1.0.0 |
| 类型 | Chrome 扩展(Manifest V3) |
| 运行环境 | Chrome / Edge 等 Chromium 内核浏览器,支持 `chrome.tabCapture` 与 `offscreen` |
| 录制范围 | 当前标签页(http/https) |
| 数据存储 | 全本地,IndexedDB 存视频与光标轨迹,不登录、不上传 |
| 导出格式 | MP4 / WebM / GIF(WebCodecs 离线编码,不支持时回退 MediaRecorder) |
| 快捷键 | `Alt+Shift+R` 开始 / 停止 |
| 权限 | `tabCapture` / `offscreen` / `storage` / `scripting` / `activeTab` / `alarms` + `http/https` host 权限(录制中跨页面导航时,自动重新注入光标追踪器需要) |
| 技术栈 | 原生 JS(ES Module)+ Canvas 2D + WebCodecs + IndexedDB,无构建步骤、无第三方框架 |

## 它和别人不一样的地方

- **快**:点图标或按 `Alt+Shift+R` 立刻起录;停止后视频本地直存,不登录、不上传、不等云端渲染。
- **酷**:借鉴 Screen Studio 的做法——录的是干净网页画面(`tabCapture`),录制时把光标换成干净的 macOS 风箭头;编辑器里再合成「跟随点击的自动运镜 + 点击波纹 + 真壁纸背景 + 圆角阴影」。8 张内置壁纸是 GPT-image 生成的 macOS 级渐变(深色 4 + 浅色 4,共 ~1MB),不是程序化渐变。
- **能剪**:胶片缩略图时间轴,拖选区即可删掉中间废片段、给片段变速,键盘快捷键 + 撤销,轻量但够用。
- **会剪**:一键「剪除空白」——没操作、也没声音的片段(发呆/等加载)自动找出来剪掉。活动信号取「光标移动 + 点击 + 键盘滚轮心跳 + 音频能量」的并集,网页里在播视频时不会被误剪;键盘只记时间戳,不记按键内容。
- **带人**:可同时录摄像头,但**不是烤死在画面里**——摄像头单独录一条轨,编辑器里作为浮动小窗合成:位置(画布上直接拖)、大小、窗口样式(圆形/方圆/卡片)、美颜(柔焦磨皮)、背景虚化(本地人像分割,不联网)、镜像、描边,全部录完后随便改,导出才合成进画面。
- **带声**:麦克风旁白同样单独成轨(自带回声消除/降噪),编辑器里网页声音和人声分轨调音量再混音;正在说话的片段不会被「剪除空白」误剪。
- **运镜可编辑**:点击自动生成的运镜段显示在时间轴上方,可删除、拖动、改时长、逐段调倍数、点画面重设焦点;没点击的片段也能选区手动加运镜。
- **光标后期化**:可选「平滑光标」录制——真实光标缩成近隐形小点,导出时重绘一个可调大小、样条平滑、点击带下压动画的光标,快速甩鼠标也丝滑。
- **多比例分发**:画布一键切 9:16 / 1:1 / 4:5,壁纸铺满、网页卡片居中,同一段录制直接出竖屏版发小红书/视频号。
- **抗崩溃**:录制切片逐秒落地 IndexedDB,长录制内存恒定;浏览器崩溃后录制库里能恢复已录的部分。剪辑/美化/摄像头配置随录制持久化,关掉编辑器再开不丢。

## 安装(开发者模式加载)

1. Chrome 打开 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」,选择本文件夹 `HuaRec-花录`
4. 建议把 HuaRec 图标固定到工具栏

## 使用

1. 在任意普通网页(http/https)上点 HuaRec 图标 → 点「开始录制」(或直接按 `Alt+Shift+R`);要出镜勾「同时录制摄像头」(有圆形预览)、要旁白勾「录制麦克风」、想要丝滑光标勾「平滑光标」(首次用摄像头/麦克风会引导授权一次)
2. 弹窗自动关闭,正常操作网页;录制全程画面干净,**不会有任何控制条被录进去**;中途点链接跳转、刷新页面都没关系,光标/点击追踪会自动接续
3. 要暂停 / 停止时:再点一次工具栏的 HuaRec 图标 → 弹窗里有计时、暂停、「停止并编辑」(或「停止·直接下载源片」跳过编辑器),也可直接按 `Alt+Shift+R` 停止
4. 停止后自动打开编辑器(默认进「美化」)
5. 编辑器里实时调:背景 / 留白 / 圆角 / 阴影 / 运镜(时间轴上方逐段编辑)/ 点击波纹 / 按键浮层 / 光标大小与平滑 / 摄像头小窗 / 两轨音量;在胶片轨道上拖选区删片段、变速或加运镜
6. 顶栏选画布比例(原始 / 9:16 / 1:1 / 4:5)、导出尺寸(原始 / 1080p / 720p)与格式(MP4 / WebM / GIF)点「导出」,或「源片」拿未加工版本

> 美化都在录制**之后**的编辑器里调,所见即所得——所以起录前不用做任何选择,点一下就录。

录制库:点编辑器顶栏或 popup 的「最近」,可重新打开、删除历史录制。

## 已知边界

- 只录**当前标签页**,不录整个桌面 / 其他应用窗口。
- 变速段的音频用 WSOLA 时间拉伸,**变速不变调**(无花栗鼠声)。
- 录制控制(计时/暂停/停止)在工具栏弹窗里,不在网页上——任何浮在网页上看得见的东西都会被 `tabCapture` 录进画面。
- 导出走 **WebCodecs 离线编码**,比实时录制快很多;浏览器不支持时自动回退为实时录制。
- MP4 导出依赖浏览器编码器支持,不支持时自动回退 WebM;MP4 音轨优先 **AAC**(QuickTime / iOS / 微信 / 剪映都能播),系统不支持 AAC 编码时退回 Opus。
- 源片 WebM 在存库前自动补写时长元数据,播放器里能正常显示时长、拖进度条。
- 录麦克风时若不戴耳机,外放的网页声音会被麦克风拾到一部分(已开回声消除,但物理上无法根除),**推荐戴耳机**。
- 「平滑光标」模式下,跨域 iframe 内部藏不掉真实光标;页面里依赖 hover 光标形态的演示(拖拽手柄等)看不到形态变化——所以默认关,按需开。
- 摄像头背景虚化用 MediaPipe 自拍分割,**模型打包在扩展里本地运行,不联网**;首次开启加载约 1-2 秒,导出时逐帧分割会稍慢。
- 按键浮层只记录「带修饰键的组合键」和非输入场景的特殊键,**纯打字内容永不记录**。
- `chrome://`、应用商店等特殊页面无法录制(浏览器限制)。

## 技术结构

```
manifest.json           MV3 配置(CSP 放行本地 wasm,供人像分割用)
background.js           编排:取流 → 拉起 offscreen → 注入隐形追踪器 → 停止合并轨迹 → 存库
offscreen.html/js       持有 MediaRecorder,三轨录制(屏幕 + 摄像头 + 麦克风);切片逐秒流式落库,长录制内存恒定
content/tracker.js      注入被录页的【隐形】追踪器:光标/点击/活动心跳/组合键;光标美化与「平滑光标」小点模式;轨迹每 4s 增量上报,跨页导航自动接续
permission.html/js      摄像头/麦克风一次性授权引导页
popup/                  一键起录(摄像头预览/麦克风/平滑光标开关)+ 录制中控制(计时/暂停/停止)
editor/render.js        渲染引擎(预览与导出共用):运镜(逐段倍数)/ 点击波纹 / 按键浮层 / 平滑光标 / 摄像头气泡(美颜+背景虚化)/ 壁纸背景 / 竖屏 contain 构图
editor/editor.js        多段剪辑模型、运镜轨编辑、胶片时间轴、三轨同步预览、两轨混音、工程持久化、崩溃恢复、录制库(封面/改名/存储占用)
editor/exporter.js      WebCodecs 离线编码导出(MP4/WebM/GIF,可选尺寸),回退 MediaRecorder
lib/presets.js          壁纸清单 + 默认皮肤预设
lib/db.js               IndexedDB v2:recordings(成品)/ chunks(流式切片)/ sessions(会话,崩溃恢复凭据)/ projects(编辑工程)
lib/vendor/fix-webm-duration.mjs   MIT 三方库:给 MediaRecorder 产出的 WebM 补写 Duration 元数据
lib/vendor/mediapipe/   MediaPipe tasks-vision + 自拍分割模型(本地运行,背景虚化用,~10MB)
assets/wallpapers/      8 张内置壁纸(GPT-image 生成,jpg;_raw/ 存原始 png,不参与运行)
```
